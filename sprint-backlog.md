## Definition of Done

A task can be marked as **Done** when:

- The agreed functionality has been implemented.
- The implementation has been tested.
- Relevant acceptance criteria have been met.
- No critical or high-priority defects remain.
- Code has been committed to the appropriate GitHub branch.
- The change has been reviewed where applicable.
- Relevant documentation has been updated.

---

## Backlog Management

The Product Manager will review the backlog with the freelancer and:

- Prioritize tasks.
- Clarify requirements.
- Review progress.
- Track blockers.
- Accept or reject completed work.
- Add new tasks when requirements change.
- Move future enhancements into a later backlog.

The backlog may be updated as the technical approach becomes clearer.
